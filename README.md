# Rsbuild project

## Setup

安装依赖：

```bash
yarn
```

进入 react-src 文件夹，安装依赖：

```bash
yarn
```

注意 React 依赖的 Node 版本为 "^12.17.0 || 13.x || 14.x || 15.x || 16.x || 17.x"。

## Get started

Start the dev server:

```bash
yarn dev
```

Build the app for production:

```bash
yarn build
```

Preview the production build locally:

```bash
yarn preview
```
